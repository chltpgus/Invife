# 화면 지도

이슈, PR, 코드에서 화면 이름은 아래 「이름」을 그대로 쓴다. 기준은 [제작 스펙 2장](./design/editor-spec.md)과 하객 경로다. 「오늘」은 master에 있는 것만 있음이다.

## 만드는 사람

| 이름 | 경로 | 오늘 |
|---|---|---|
| 시작 | `/` | 일부. 지금은 샘플 초대장 목록만 있다. 무료로 만들기, 이미 만든 청첩장 보기, 이어서 하기는 없다 |
| 테마 선택 | `/new` | 없음. 테마 3종, 신랑 이름, 신부 이름, 예식 날짜와 시간 |
| 편집 | `/edit/[id]` | 없음. 섹션 폼, 실시간 미리보기, 자동 저장, 사진 업로드·초점·필터, 발행하기 |
| 전체 미리보기 | `/edit/[id]/preview` | 없음 |
| 발행 | `/edit/[id]/publish` | 없음. 발행 점검, 카카오 로그인 |
| 발행 완료 | `/edit/[id]/published` | 없음. 카카오톡으로 보내기, 공용 초대장 링크 복사, 공용 RSVP 링크 복사 |
| 내 초대장 | `/dashboard` | 없음 |
| 하객 명단 | `/dashboard/[id]/guests` | 없음. 받는 사람별 링크 |
| RSVP 집계 | `/dashboard/[id]/rsvp` | 없음. 참석 인원, 불참, 미응답 |
| 초대장 설정 | `/dashboard/[id]/settings` | 없음. 발행 취소, 삭제 |

광고 자리는 테마 선택, 발행 완료, 내 초대장에만 있고 출시 때는 꺼 둔다. 아직 없다.

## 하객

세 경로는 초대장 한 장이다. `/g/`, `/s/`는 그 파일로 다시 쓴다.

| 이름 | 경로 | 오늘 |
|---|---|---|
| 공용 초대장 | `/i/{slug}/` | 있음 |
| 받는 사람 초대장 | `/i/{slug}/g/{token}/` | 있음 |
| 공용 RSVP | `/i/{slug}/s/{token}/` | 있음 |
| 찾을 수 없음 | 없는 슬러그, 또는 참석 맥락이 없을 때 | 있음 |
| 끝난 행사 | 같은 초대장. 예식 다음 날부터 | 있음 |

초대장 안에서 위에서 아래 순서다.

| 이름 | 오늘 |
|---|---|
| 봉투 오프닝 | 있음 |
| 커버 | 있음 |
| 인사말 | 있음. 화면 제목은 초대합니다 |
| 양가 혼주 | 있음 |
| 연락하기 | 있음 |
| 일시와 달력 | 있음 |
| 갤러리 | 있음. 전체 화면 뷰어를 포함한다 |
| 오시는 길 | 있음. 지도, 주소 복사, 지도 앱 |
| 마음 전하실 곳 | 있음 |
| 참석 여부 | 있음 |
| 하단 바로가기 | 있음. 오시는 길, 마음 전하실 곳, 참석 여부 |
| 카카오톡으로 공유 | 있음. 키가 없으면 버튼만 둔다 |
