## 1. 원칙 [결정]

- 잡지 화보 같은 에디토리얼 톤, 넉넉한 여백, 종이 배경 + 포인트 색 1개.
- 꽃·리본 등 클립아트 없음. 장식은 타이포·가는 선(hairline)·여백으로만.
- 색 테마 3종 고정, 폰트·레이아웃 고정(제작자는 테마·사진·문구만 바꿈).
- **라이트 전용.** 시스템 다크모드를 따르지 않음 (`<meta name="color-scheme" content="only light">`, `:root{color-scheme: only light}`).
- **하객 화면 광고 없음.** `/i/*`에 광고 스크립트 금지(CSP로 광고 도메인 차단).
- 정보 섹션(오시는 길·계좌·RSVP·연락하기)에는 모션 없음.

### 2.2 폰트 [결정]

| 용도 | 패밀리 | 로드할 굵기 | 라이선스 |

| 본문·UI(고딕) | **Noto Sans KR** | 400, 500 | SIL OFL 1.1 |

### 2.4 간격 · 반경 · 그림자 [결정]

- **Space (4pt)**: `0, 4, 8, 12, 16, 20, 24, 32, 40, 48, 56, 64, 80` (토큰 키 `space.0…20` = n×4).
- 레이아웃 상수: 좌우 거터 24 · 콘텐츠 폭 `min(100% - 48px, 382px)`(390에서 342) · 섹션 상하 패딩 80 · 섹션 내부 간격 32 · 최소 터치 영역 44×44.
- **Radius**: `none 0`(사진·아코디언·지도) · `sm 4`(버튼·입력·스테퍼) · `md 8`(예비) · `pill 999`(토스트·바로가기 바·원형 아이콘 버튼).
- **Shadow**: 기본은 그림자 없음(종이 평면). `envelope 0 12px 32px rgba(31,27,22,.10)` · `floating 0 2px 12px rgba(31,27,22,.08)`(바로가기 바) · `toast 0 4px 16px rgba(31,27,22,.16)`.
- **Border**: 장식 `1px line` · 컨트롤 `1px text2` · 포커스 `2px solid accent, outline-offset 2px`.

## 3. 사진 크롭 비율 [결정]

| 자리 | 비율 | 390 기준 크기 | 규칙 |
|---|---|---|---|
| 커버 | 4:5 | 390×488 | 높이 = `min(폭×1.25, 100svh − 216px)` → 짧은 화면에서 가로로 넓어짐. `object-fit: cover` |
| 갤러리 대표(1번) | 4:5 | 342×428 | |
| 갤러리 썸네일(2–10번) | 1:1 | 111×111 | 3열, 간격 4 |
| 전체 화면 뷰어 | 원본 | contain | 잘리지 않음 |
| 지도 | 3:2 | 342×228 | 예식장 핀 중앙 |
| 봉투 속 카드 | 4:5 | 커버와 동일 이미지 | 연출 끝에 커버 사진 자리와 정확히 겹쳐야 함 |
| OG 이미지 | 2:1 | 1200×600 | 10장 참고 |

- 모든 크롭은 제작자가 지정한 **초점(focal point, x·y 0–1)** 으로 `object-position: {x*100}% {y*100}%`.
- 로딩 전 자리: `aspect-ratio`로 고정 + 흐린 미리보기(LQIP, ~24px 폭 base64 인라인 → CSS로 확대, `filter: blur` 대신 이미지 자체를 흐리게 저장 권장). 레이아웃 이동(CLS) 0.
- `srcset`: 800 / 1200 / 1600w WebP. 대표(커버)만 `fetchpriority="high"`, 나머지 `loading="lazy"`. 뷰어는 1600w만.

## 4. 뷰포트 · 반응형 · 카톡 인앱 [결정]

- **지원 폭 360–430px**, 디자인 기준 390. 360 미만(예: 320)은 깨지지 않게만(가로 스크롤 금지, 3열 썸네일 유지).
- **데스크톱/태블릿(>430px)**: 가운데 단일 컬럼 `max-width: 430px; margin: 0 auto;` 컬럼은 `bg`, 바깥은 `outer` 단색, 컬럼 좌우 `1px line`. 확대·2단 레이아웃 없음. 고정 요소(바로가기 바·토스트)도 컬럼 폭 안에서 가운데 정렬(`left:50%; transform:translateX(-50%); width:min(100%,430px)`).
- 높이: `100svh`(폴백 `100vh`) 기준. 커버는 **360×640 + 카톡 인앱 상단바(≈56)/하단 툴바(≈48)** 에서도 사진·이름·일시·예식장이 스크롤 없이 보여야 함(커버 텍스트 블록 216px 고정 예산).
- Safe area: `viewport-fit=cover` + 하단 고정 요소에 `env(safe-area-inset-bottom)`.
- 카톡 인앱: 가로 스와이프 = 뒤로가기와 충돌하므로 페이지 레벨 가로 제스처 금지(뷰어 내부만). 뷰어/모달은 `history.pushState`로 한 단계 추가해 뒤로가기 = 닫기.
- 다크모드 강제 반전(안드로이드 카톡 인앱): `color-scheme: only light` 적용 후 **실기기 확인 필요**(기획안 10장).
- 성능 목표: 저사양 안드로이드 카톡 인앱 첫 화면 약 2.5초. 텍스트는 정적 HTML에 포함, 커버 이미지만 우선 로드.

## 6. 봉투 오프닝 [결정]

- **첫 방문에만**: `localStorage['invife:opened:{invitationId}']`가 없을 때. 열거나 건너뛰면 기록. 재방문은 바로 커버. localStorage 불가(사생활 모드 등)면 매번 봉투가 나와도 무방하나 건너뛰기 항상 노출.
- 화면 구성: 종이 배경, 가운데 봉투(폭 `min(300px, 78vw)`, 3:2), 위에 `THE WEDDING OF` + 이름(`displayName`), 아래 `2027. 05. 15`(`displayDate` 축소 또는 bodyStrong), 하단 `arrow-up` 아이콘 + 「탭하거나 위로 밀어서 열기」(caption), 우상단 「건너뛰기」(텍스트 버튼, 44×44).
- 봉투 위 모노그램 원(이니셜, accent 원 + onAccent 명조)은 [제안] — 타이포 요소라 클립아트 아님. 빼도 무방.
- **트리거**: 봉투(전체 영역 `role="button"`, `aria-label="초대장 열기"`) 탭 · 위로 스와이프(세로 이동 ≥48px 또는 속도 ≥0.3px/ms, 가로 우세 제스처는 무시) · Enter/Space.
- **타임라인 (총 1800ms ≤ 2s)**
  1. 0–300 덮개 열림 (`envelope-flap-closed` → `envelope-flap-open`, rotateX, inOut)
  2. 300–1100 커버 카드가 봉투에서 올라옴 (translateY, enter)
  3. 900–1400 봉투 몸체 페이드 아웃 (exit)
  4. 1100–1800 카드가 커버 사진 자리(4:5 rect)로 확대·이동 — **끊김 없이** 실제 커버 이미지와 교체 (FLIP 권장, inOut)
  5. 이후 커버 텍스트 400ms 페이드 인 (봉투 연출 시간에 포함 안 됨)
- **건너뛰기**: 「건너뛰기」 또는 연출 중 두 번째 탭 → `base` 200 크로스페이드로 커버.
- 커버 이미지 미로딩: LQIP로 연출 진행(로딩을 기다리지 않음).
- 레이어 SVG: `assets/envelope/` (6장 끝 표). 연출 중 스크롤 잠금, 종료 후 해제.

## 7. 섹션별 레이아웃과 상태 (기획안 4장 순서)

> 순서: 커버 → 인사말 → **양가 혼주 성함 · 연락하기** → 일시·달력 → 갤러리 → 오시는 길 → 마음 전하실 곳 → 참석 여부. 기획안(PR #1, `515effb`) 4장 1–9번 순서 그대로입니다(3 양가 혼주 성함, 4 연락하기).

공통 섹션 틀: `<section aria-labelledby>` · 패딩 80/24 · 가운데 정렬 · 헤더 = eyebrow(영문, `aria-hidden`) + heading(h2) · 섹션 사이 구분은 여백만(필요 시 24px hairline).

**빈 값 규칙 총칙**: 선택 항목이 비면 그 줄/블록만 숨김. 섹션의 필수 내용이 전부 비면 섹션 전체와 바로가기 항목을 숨김. 빈 제목·빈 카드·「정보 없음」 문구는 절대 노출하지 않음.

### 7.1 커버
- 구성: 사진(4:5, 3장 규칙) → 종이 위 텍스트 블록(216px): eyebrow `THE WEDDING OF` · 이름 `김민준 · 이서연`(h1, displayName) · `2027. 05. 15 SAT · 오후 1시`(bodyStrong, `<time datetime>`) · 예식장 `더채플앳청담 3층 그레이스홀`(body, text2). 하단 스크롤 힌트 chevron-down(장식).
- 텍스트는 사진 위에 올리지 않음(어떤 사진이든 대비 유지).
- 빈 값: 사진 없음 → 사진 자리 없이 텍스트 블록을 화면 세로 중앙에 + 큰 날짜(`displayDate`) 추가[제안]. 홀 이름 없음 → 예식장명만. 시간 없음 → 날짜·요일만.
- 상태: 사진 로딩(LQIP) / 사진 실패(`surface` 자리 유지, 텍스트 그대로).
- 사진 alt: 「{신랑}과 {신부}의 웨딩 사진」 자동 생성.

### 7.2 인사말
- heading「초대합니다」, 본문(body, 가운데, 제작자 줄바꿈 유지, 권장 3–6줄, 최대 폭 342), 24px 가로선, 서명 caption「민준 · 서연 드림」.
- 빈 값: 인사말 없음 → 섹션 숨김. 서명은 이름에서 자동 생성.

### 7.3 양가 혼주 성함 · 연락하기
**혼주 성함 블록**: `김철수 · 박영희 의 아들 민준` / `이정훈 · 최미경 의 딸 서연`. 부모 이름은 text2, 본인 이름 bodyStrong. 관계어(아들/딸)는 제작자 입력 [미정 Q2: 장남/차녀 등].

**고인 표기 [결정: 세현]**
- 제작자가 부모별로 「고인」 체크 + **표기 방식 선택**: `故 김철수`(한자 접두) / `고 김철수`(한글 접두) — 옵션 값 `'hanja' | 'hangul'`. [제안] 표시 안 함 옵션도 둘지는 [미정 Q3].
- 접두어는 이름과 같은 색(text2), 크기 동일, 이름 앞 공백 1칸. 국화 아이콘 등 그림 표기 없음.
- 스크린리더: `故`는 `aria-label="고 김철수"`로 읽히게(한자 단독 발음 보장).
- 예: `故 김철수 · 박영희 의 아들 민준`

**연락하기 블록**: 신랑측 / 신부측 그룹, 각 행 = 관계 caption + 이름 bodyStrong + 원형 아이콘 버튼 2개(전화 `tel:`, 문자 `sms:`, 44×44, 테두리 text2).
- **고인으로 표시된 사람: 연락 버튼 숨김 [결정: 세현]** → 버튼이 없으면 행 자체를 연락하기 목록에서 제외 [제안](이름만 남은 빈 행 방지).
- 빈 값: 번호 없는 사람 → 그 행 제외. 그룹 전원 없음 → 그룹 제외. 전체 없음 → 연락하기 블록 숨김. 혼주 성함 미입력 → 그 줄 숨김(양쪽 다 없으면 블록 숨김).
- 데스크톱(전화 불가): 번호 텍스트 + 복사 버튼으로 대체.
- aria-label: 「김민준에게 전화하기」「김민준에게 문자 보내기」.

### 7.4 일시와 달력
- 큰 날짜 `05.15`(displayDateXL 88) → `2027년 5월 15일 토요일`(bodyStrong) → `오후 1시 · 예식장`(body text2) → 달력.
- 달력: 월 제목(title), 일요일 시작 7열, 선 없음, 숫자만, **예식일만 accent 원(40px) + onAccent 굵게**. 셀 폭 = 콘텐츠폭/7(360에서도 7열, 높이 44).
- 접근성: `<table>` + `<caption>2027년 5월</caption>`, 예식일 셀 `aria-label="5월 15일 토요일 예식일"`(색 + 원 + 굵기).
- 빈 값: 시간 없음 → 날짜만. (날짜는 발행 필수값.)
- 캘린더 추가 · D-day 없음(기획 범위 밖).

### 7.5 갤러리 + 전체 화면 뷰어
- 10장 = 대표 1(4:5) + 9장 1:1 3열(간격 4). 1장 → 대표만. 2–9장 → 대표 + 나머지(마지막 줄 왼쪽 정렬). **0장 → 섹션 숨김.** 캡션 caption「사진을 누르면 크게 볼 수 있어요」.

### 7.8 참석 여부 (RSVP)
**받는 값**: 참석 여부(참석/불참, 필수) + 동행 인원(참석일 때만, **0–10명, 본인 제외**) + 이름(필수, 링크 종류별 처리는 아래). **식사 여부는 받지 않음**(기획안 4장 9번).

**레이아웃**: heading「참석 여부」 + 안내 body text2 → (이름 영역) → 참석 라디오 2개(세로, 각 높이 52, surface, 테두리 text2, 선택 = accent 배경 + onAccent + check 아이콘) → (참석 시) 동행 인원 스테퍼 → 마감 안내 caption「5월 8일(토)까지 수정할 수 있어요」 → 주 버튼「참석 여부 전달하기」(폭 100%, 높이 52, radius 4).

**이름 영역**
- **받는 사람별 링크 [기획안 5장]**: 초대장 본문(커버 등)에는 받는 사람 이름을 **옵션 없이 항상** 띄우지 않음. RSVP에서만 이름 칸을 자동으로 채운 요약 박스(surface, 「김지훈 님으로 응답해요」) + 링크 「김지훈 님이 아니신가요?」(accent, 밑줄) → 탭하면 일반 이름 입력 필드로 바뀌어 수정 가능(재공유 대비).
- **공용 링크: 이름 입력 [결정]** — 라벨「이름」, placeholder「이름을 입력해 주세요」, 1–20자(앞뒤 공백 제거), `autocomplete="name"`. Turnstile(managed, 대부분 비노출)은 **공용 초대장과 공용 RSVP 링크 둘 다** 적용한다. 위젯 자리는 버튼 위 65px 예약.

**동행 인원 스테퍼 [결정: 세현]**
- 라벨「동행 인원」 + caption「(본인 제외)」, `− [n명] +` (버튼 44×44 radius 4, 값 bodyStrong tabular, `aria-live="polite"`).
- 기본 0. **0이면 − disabled, 10이면 + disabled** + caption「최대 10명까지 함께 오실 수 있어요」. `aria-label="동행 인원 줄이기/늘리기"`, disabled는 `aria-disabled="true"` + opacity .4.
- 불참 선택 시 스테퍼 숨김, 값은 0으로 전송.

- **마감 판단은 서버 기준**(제출 API가 마감 후 거부 → Closed로 전환). 페이지는 정적이므로 로드 시 클라이언트 시계로 1차 표시, 제출 응답으로 확정. 시간대 KST.
- 마감 미설정 시 기본값 [미정 Q7, 제안: 예식 전날 23:59 KST].
- 공용 링크: 같은 기기의 중복 응답은 localStorage 응답 ID로 막고 기존 응답 수정으로 처리(기획안 7장). 다른 기기에서는 새 응답이 됨 — 호스트 화면의 중복 처리 방식은 editor-spec 참고 [미정].
- 바로가기 바는 키보드가 열려 있는 동안 숨김.

### 7.9 하단 바로가기 바
- 항목(텍스트만, label 14): `오시는 길` · `마음 전하실 곳` · `참석 여부`. 아이콘 없음.
- 형태: 화면 하단 16px + safe-area 위에 떠 있는 pill(높이 56, 좌우 24 여백, surface, 테두리 line, shadow floating). 항목은 균등 폭, 각 터치 영역 ≥44.
- 표시: 커버를 80% 지나면 등장, 커버가 다시 보이면 숨김. 봉투 연출·뷰어 열림·키보드 열림 중 숨김.
- 현재 보이는 섹션 = text + 500 + accent 밑줄(offset 6), `aria-current="true"`. 나머지 text2.
- 탭 → 해당 섹션으로 부드러운 스크롤(움직임 줄이기면 즉시). 「마음 전하실 곳」은 양쪽 펼친 채 이동.
- 빈 값: 해당 섹션이 숨겨지면 항목 제외. 0개면 바 없음. 페이지 하단에 바 높이 + 32 여백(마지막 버튼을 가리지 않게).
- `<nav aria-label="바로가기">`. 광고 없음.

## 9. 접근성

- 대비: 2.1 표 — 모든 텍스트 AA 이상. `line`은 장식 전용.
- 터치 영역 ≥ 44×44. 의미 있는 텍스트 ≥ 13px, 본문 15px, rem 단위.
- 시맨틱: 커버 이름 h1, 섹션 h2, 일시 `<time datetime>`, 달력 `<table>`, 바로가기 `<nav>`, 뷰어 `dialog`, 라디오 `radiogroup`, 아코디언 `button[aria-expanded]`.
- 색만으로 구분 금지: 선택 = 색 + check, 예식일 = 색 + 원 + 굵기, 현재 항목 = 굵기 + 밑줄, 오류 = 색 + 아이콘 + 문구.
- 포커스: `:focus-visible` 2px accent 링. 뷰어 포커스 가두기/복귀. RSVP 성공 시 결과 제목으로 포커스, 오류 시 배너/필드로.
- 영문 eyebrow는 `aria-hidden="true"`(한국어 h2가 제목 역할).
- 사진 alt 자동 생성(커버·갤러리 n/10·지도). 장식 SVG `aria-hidden`.
- 움직임 줄이기 존중(5.3). 자동 재생 소리·영상 없음.
- `lang="ko"`, 페이지 title = 「김민준 · 이서연 결혼식에 초대합니다」 형태(기호 ♥ 등 없이) [제안].
