# Invife

> **Invite to life** — Invife (인바이프)는 *invite*와 *life*를 합친 이름이에요.

무료 모바일 청첩장 서비스(사이드 프로젝트)입니다. 이 저장소는 기획과 개발을 함께 담는 공간이에요.

## 서비스 소개

누가 만들어도 잡지 화보처럼 예쁘게 나오는 **무료 청첩장**을 목표로 합니다. 하객 화면에는 광고가 없어요.

하객이 청첩장에서 중요하게 보는 것은 청첩장이 얼마나 예쁜지, 그리고 결혼식 정보가 잘 전달되는지입니다. 즐거움은 퀴즈 같은 기능을 더해서가 아니라 **디자인**에서 주기로 했어요. 처음에는 청첩장 하나로 시작하고, 돌잔치나 생일파티 같은 다른 행사는 출시 후 같은 틀에서 문구와 색만 바꿔 확장하는 방향이에요.

## MVP 범위 요약

| 항목 | 결정 |
|---|---|
| 템플릿 | 청첩장 1종, 색 테마 3~6개 |
| 사진 | 최대 10장, 얼굴 위치 지정과 색감 필터 |
| 연출 | 봉투 오프닝, 스크롤 등장 효과 |
| 로그인 | 카카오 로그인과 비회원 작성 |
| 하객 관리 | 받는 사람별 링크, 미응답자 목록, 인원 합계 |
| 공유 | 카톡 공유 버튼과 링크 복사, 공용 RSVP 링크 |
| 결제 | 없음 (당분간 무료) |
| 광고 | 만드는 사람 화면에만, 출시 때는 꺼둠 |

자세한 내용은 [MVP 최종 기획안](./docs/planning/mvp-plan.md)을 참고하세요.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 프론트엔드 | Next.js, TypeScript |
| 백엔드 | Supabase (DB, 로그인, 접근 권한) |
| 이미지 저장 | Cloudflare R2 |
| 호스팅 | Vercel 또는 Cloudflare Pages |

초대장 페이지는 정적으로 만들어 CDN으로 제공하고, DB가 멈춰도 보이도록 합니다.

## 저장소 구조

```
.
├── docs/       # 기획·설계 문서
├── frontend/   # Next.js 프론트엔드
└── backend/    # Supabase 연동 및 서버 로직
```

## 6주 일정 요약

| 주차 | 작업 |
|---|---|
| 1주차 | 프로젝트 세팅, 폰트와 색 테마 확정, 청첩장 템플릿 뼈대 |
| 2주차 | 만들기 화면, 사진 업로드와 크롭, 크기별 변환, 색감 필터 |
| 3주차 | 공개 초대장 페이지, 갤러리, 카톡 미리보기, 스크롤 등장, 흐린 미리보기, 하단 바로가기 |
| 4주차 | 받는 사람별 링크, RSVP 집계, 미응답자 목록, 호스트 관리 화면 |
| 5주차 | 봉투 오프닝, 비회원 작성, 남용 방지, 예산 알림 |
| 6주차 | 카톡 인앱, iOS Safari, 저사양 안드로이드 실기기 점검, 약관, 베타, 출시 |

일정이 밀리면 광고 코드를 출시 직후로 옮겨 이틀 정도 여유를 만들 계획이에요. 6주차 점검 기간은 줄이지 않아요.
